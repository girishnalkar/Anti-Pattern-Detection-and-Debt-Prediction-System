# Anti-Pattern Detection and Technical Debt Prediction System

An intelligent, machine-learning-powered web application that analyzes Python GitHub repositories to detect code anti-patterns, calculate technical debt, and predict the overall risk level of the codebase.

## 🚀 Features

- **Automated Repository Cloning:** Fast, shallow cloning of any public GitHub repository directly into temporary storage to avoid cluttering your local file system.
- **Static Code Analysis:** Computes key metrics including Lines of Code (LOC) and cyclomatic complexity (via Radon).
- **Anti-Pattern Detection:** Automatically identifies common bad practices such as:
  - **God Classes** (Classes with too many methods/responsibilities)
  - **Long Methods** (Methods with excessive length or complexity)
  - **Duplicate Code** (Cross-file similarity analysis to catch copied-and-pasted code)
- **Technical Debt Index (TDI):** Calculates a normalized score to help developers understand the maintainability of their code.
- **Machine Learning Risk Prediction:** Uses a trained Random Forest model (`risk_random_forest_model_v3`) to analyze the extracted metrics and output a predicted Risk Label (e.g., Low, Medium, High) with an associated confidence score.
- **Interactive Web Interface:** A seamless Flask-powered backend serving a clean, dynamic frontend for kicking off analyses, monitoring progress, and viewing beautiful metric reports.

## 🛠️ Tech Stack

- **Backend:** Python, Flask, Flask-CORS
- **Code Analysis:** GitPython, Radon, standard AST
- **Machine Learning:** Scikit-Learn, Pandas, NumPy, Joblib
- **Frontend:** Vanilla JS / HTML / CSS served statically by Flask

## 📋 Prerequisites

- **Python 3.8+**
- **Git** installed and available in your system's PATH.

## ⚙️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/girishnalkar/Anti-Pattern-Detection-and-Debt-Prediction-System.git
   cd Anti-Pattern-Detection-and-Debt-Prediction-System
   ```

2. **Create a virtual environment (recommended):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate
   ```

3. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Ensure that packages like `flask`, `flask-cors`, `gitpython`, `radon`, `scikit-learn`, `pandas`, `numpy`, and `joblib` are installed).*

## 💻 Usage

1. **Start the Flask server:**
   ```bash
   python api.py
   ```
   *Note: `api.py` acts as the main entry point and serves both the API endpoints and the static frontend.*

2. **Open the web interface:**
   Navigate to [http://localhost:5000](http://localhost:5000) in your browser.

3. **Analyze a Repository:**
   - Enter a valid public GitHub repository URL (e.g., `https://github.com/psf/requests`).
   - Click "Analyze" and wait for the system to process the files.
   - Once complete, view the detailed metrics and the ML-powered risk prediction.

## 🔌 API Reference

The backend exposes the following RESTful endpoints:

- `GET /` - Serves the main UI.
- `POST /api/analyze` - Triggers a background analysis. Expects JSON: `{"repo_url": "https://..."}`.
- `GET /api/status` - Returns the current status of the background analysis (`running: true/false`, and any `error`).
- `GET /api/report` - Retrieves the detailed JSON report generated by the analysis.
- `GET /api/predict` - Uses the pre-trained ML model to evaluate the latest report and return a risk label and confidence score.
- `POST /api/cancel` - Cancels an ongoing analysis.

## ⚠️ Notes

- The ML models are tracked via Git but represent large binaries (~50MB). If you plan to scale the models, consider integrating **Git LFS**.
- Cross-file duplicate code detection is an $O(n^2)$ operation. For repositories exceeding 150 files, this step is automatically bypassed to ensure fast analysis times.
